⚡ INICIO RÁPIDO
==================

## 🚀 Desarrollo Local

npm install
npm start

La app correrá en: http://localhost:5173
El API en: http://localhost:3000

## 🌐 Deploy a Vercel

1. Ir a https://vercel.com
2. Click "Add New Project"
3. Importar tu repositorio
4. Click "Deploy"
5. ¡Listo! ✅
